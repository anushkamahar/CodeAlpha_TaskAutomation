# Task-Automation

This is a simple Python script that moves JPG files from one folder to another.

## About the Project

The script checks the `photos` folder for JPG files. It creates a `jpg_files` folder inside the `photos` folder and moves all the JPG files into it.

## Features

* Finds JPG files from the `photos` folder
* Creates the `jpg_files` folder automatically
* Moves JPG files to the new folder
* Displays the names of the files that are moved

## Technologies Used

* Python
* os
* shutil

## How to Run

Make sure Python is installed.

Keep the JPG files inside the `photos` folder and run:

```bash
python TaskAutomation.py
```

After running the script, the JPG files will be moved to the `photos/jpg_files` folder.

## Project Files

* `TaskAutomation.py` - Main Python file for the automation.
* `photos` - Folder containing sample JPG files.
* `README.md` - Information about the project.
